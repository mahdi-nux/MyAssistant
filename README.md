# MyAssistant

A simple local AI chat assistant built with **Rust**, **Iced**, **Tokio**, and **Candle**.

MyAssistant is a desktop application that runs a local language model and provides a native chat interface without relying on a remote AI API.

## Features

* 🖥️ Native desktop interface built with Iced
* 🦀 Written in Rust
* 🤖 Local LLM inference with Candle
* ⚡ Async operations with Tokio
* 🔒 No external AI API required

## Technologies

* [Rust](https://www.rust-lang.org/)
* [Iced](https://iced.rs/)
* [Tokio](https://tokio.rs/)
* [Candle](https://github.com/huggingface/candle)

## Status

🚧 **Work in progress**

The project is currently under development. The main goal is to build a simple and practical local AI assistant while learning more about Rust, desktop application architecture, and local LLM inference.
